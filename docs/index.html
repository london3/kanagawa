ダッシュボード上で「神奈川県」を選択すると約700指標の値・地図・グラフが表示されます。

関連ダッシュボード・データカタログ

  • 指標のデータをみる 約700指標の収録期間・出所一覧
  • 2つの指標の関係性をみる 任意2指標を散布図で相関確認
  • 4つの指標の推移を並べてみる 最大4指標の時系列を地域比較
